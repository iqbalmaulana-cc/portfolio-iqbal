# Aturan Proyek Web
1. Gunakan hanya HTML5, CSS3 murni, dan JavaScript murni.
2. Jika ada database, WAJIB gunakan PHP Native dan MySQL (mysqli) agar jalan di XAMPP dan cPanel standar.
3. Pisahkan kode dengan rapi dan beri komentar bahasa Indonesia.
4. Desain harus responsif (bisa dibuka di HP) memakai Flexbox/CSS Grid.
5. Gunakan file koneksi terpisah bernama koneksi.php untuk database.
6. Cara penulisan kode harus sesuai dengan gaya penulisan saat ini.
7. Pembuat adalah programmer web pemula: jelaskan dengan bahasa sederhana dan hindari teknik yang terlalu rumit.

Aturan: jangan mengubah, menambah, atau mengarang isi teks di luar perintah. Kalau ada bagian yang kurang (misalnya link Instagram atau nomor WhatsApp), beri placeholder jelas seperti `#LINK-INSTAGRAM` dan beri tahu Iqbal.

## Struktur Halaman (sesuai kerangka)
Header -> Hero -> Tentang -> Pencapaian -> Galeri -> CTA + Kontak -> Footer

## Tema desain web
1. Tema: modern dark theme.
2. Heading: font serif (contoh: Libre Baskerville / Playfair Display).
3. Paragraf: font sans-serif (contoh: Inter / Arial).
4. Warna disimpan sebagai CSS variable di `:root` agar mudah diganti.
5. Pakai satu warna aksen saja. Pastikan kontras teks dan latar mudah dibaca.
6. Desain harus identik dengan karakter brand, bukan sekadar menarik (sesuai mindset desainer Iqbal).
